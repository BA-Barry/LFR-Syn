# Continuation from LFR-Syn to FICEL-Syn

The manuscripts in `manuscripts/` are the completed earlier writing. The current continuation is [FICEL-Syn V5.2.5](ficel-v5.2.5/README.md), dated 7 November 2026. It studies how controlled, source-conditioned intervention evidence could improve computed route availability and eventually the generator's native outputs. Task value is separately reportable and is not automatically a hard constraint.

The six modules are HCRA (interventions and root outcomes), CEMA (conditional cross-source effects), E-Builder (executable lessons), E-Gate (apply/verify/fallback), E-Learner (typed component learning), and ScoreBridge (generation training and evaluation). They are six responsibilities, not six demonstrated independent innovations.

The full six-algorithm scheme has not been executed. A standard-library numerical reference checks small handcrafted cases of the declared hierarchical model. It does not implement reaction planning, a complete evidence learner or a generator-feedback experiment. Historical B/Q code and evidence remain useful assets but do not establish the new six-module claims.

The earlier V5.2 Markdown chapters are explicitly an earlier revision, not the latest specification. The V5.2.5 Word document is authoritative for the current full equations and finite instance. Later formal changes to the research core still require the owner's decision.
