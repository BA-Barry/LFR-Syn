# 现有算法贡献解释与后续发展判断

更新：2026-10-29。承接10月23日的证据整理。本轮回答作者选定的问题：**现有算法为什么有效或无效，各步骤到底贡献了什么。** 以下是保存结果的重新整理和解释，不是新增独立实验；正式核心尚未选定，论文继续暂停。

## 1．先调整贡献判断的标准

作者明确：不追求“绝对原创”或“从未有人做过”，相似研究不能单独成为否定方向的理由。本项目此后按以下问题判断价值，而不是按有没有先例判断去留：

1. 现有方案具体哪里不足？这个不足是否关系到提高分子可合成性的目标？
2. 我们改变了哪个实际决定、操作或问题组织方式？即使借用成熟方法，适配是否解决了真实困难？
3. 与最接近的完整方法和合理简单方案相比，新增了什么：路线产出、计算效率、任务保留、适用范围、可靠性或更清楚的决策依据？
4. 额外收益是否值得增加的复杂度与成本？在什么条件下值得，什么条件下普通方法已经足够？
5. 当前版本不足时，是否有能具体说明的改进途径？改进应接上已发现的原因，而不是不断更换术语和追加尝试。

这些是讨论问题，不是新增门禁。已有类似原理、公式或组件，影响贡献定位和比较对象，不自动取消研发价值；也不要求必须发明新的数学工具才能贡献方法。有效的任务适配、组合设计和问题重组都可能形成贡献，规模取决于实际解决的问题和证据。反过来，正向结果也不自动等于足够的论文贡献。

因此，旧记录中的“主要原创尚未成立”只保留为当时尚未完成充分比较的判断，不能继续解释成“有先例所以不值得做”。R1、R2及旧B/Q资产保留；本次没有自动启动其中任何训练或搜索。

## 2．现有流程究竟做了什么

```text
来源分子及原任务分数、原路线结果
  → 找到能够正向重放回来源结构的反应拆分
  → 确定缺失前体和反应角色兼容的库存砌块
  → A/B/C等政策决定优先尝试哪些砌块
  → 有限反应组合，产生真实的新候选结构
  → QED及任务资格筛选，候选排序
  → 在第一、第二候选间分配有限路线搜索预算
  → Q/S2决定固定候选的库存查询与解码调度
  → 接受有保存审计路线的替代物；否则回退原结构
```

**结构改变、资格政策、预算分配、路线识别和生成器学习，是不同作用层。** B改变前体检索，从而改变实际形成的候选；Q改变固定候选的路线识别。只有更新生成器并评价未经上述修复的新输出，才是在检验生成分布是否改善。

本文简称：A＝Morgan前体相似检索；B＝前体条件任务贡献检索；C＝环境与权重对应关系的组内置乱检索，不是均匀随机；Q＝跨轮次库存查询调度；S2＝公共完成态优先库存保护政策。旧文件两个“S”分别指来源贡献检索、SA/MW简单检索，不能与S2混用。

## 3．已有结果如何解释各步骤

| 步骤与问题 | 已有对照结果 | 当前可保留的贡献与边界 |
|---|---|---|
| B是否只靠放宽规则？ | 旧严格512中路线A276、B361、C303；B对A为106赢、21输，净85 | 相同严格资格下，B的检索形成政策有实际作用。106个赢例中94个发生在A没有RF合格候选的环节，因此重要价值是提供合格且有路线的替代物；不能把全部增益都解释为候选本身合成难度下降。 |
| B中“缺失前体条件”有没有用？ | 与只用来源贡献的检索比较，同一最终结构分别由两规划器评价，双规划器可解B298、对照257–258；8次旧运行方向均正 | 在同资格、库存和预算上限下，信息与待替换前体相结合有具体方法增量，不能由资格放宽解释。不是新来源独立验证，也不直接证明失败学习或实验室合成成功。 |
| 库存与反应构造是否只是配套实现？ | 保留前体政策对照中资格覆盖均113；B路线117→74，C119→66 | 共同结构构造政策影响路线产出，应保留为实质作用。该对照同时改变相关构造条件，不能把全部差值分配给一个孤立组件；最终规划路线也不一定等于形成配方。 |
| 固定任务门槛为什么提升很大？ | GraphGA1024同B形成池，严格→固定路线221→913；C215→935 | 放开“不得低于来源RF”的限制，允许访问原本被排除的真实替代结构。它是资格政策收益，B/C都获益，不能全算成B特有算法贡献。固定资格仍保留任务门槛与QED要求。 |
| 候选间预算分配有没有独立作用？ | T2同B池、同严格资格、总12调用/45秒：首候选12→两候选6+6，路线335→361，29赢3输 | 第二候选全部贡献了29个新增路线，其中27个RF低于第一候选、2个同分。说明单押最高RF候选会错过路线机会；同时有截断首候选的损失。它不是新合成评分器，也不是放宽资格。 |
| 根覆盖为什么独立增益较小？ | 独立1024普通B984、根覆盖987；350次第二候选预选改变，仅13次真正访问不同第二候选，其中4赢1输 | 337次预选改变被已成功的第一候选挡在执行之外。瓶颈是决策很少实际生效，而非“改了很多排序却毫无作用”。这能指导是否继续投入，不必再重跑相同批次。 |
| Q能否改善完整流程？ | 固定B候选的128来源，Q103、S2 99，4赢0输；另1015来源已计路线时间约降29.7% | Q有有限预算内路线识别和计算效率价值。128的4个新增中1个涉及45秒时间边界；不能称分子结构更易合成，也不能把路线阶段时间说成完整端到端加速。 |
| 失败前沿是否提供额外的选点信息？ | 新60来源共同首候选解43；余17项中前沿回退与普通备选均救13，各独赢4，最终均56/60 | 当前版本的修复有结构效果，但额外机会这个简单解释足以解释总体增益。值得保留动作工具；若发展该方向，要改变信息如何影响选择，而非重复扩大相同试验。 |
| 结构编辑块能否解释个案？ | 五组完整四格：0011两组、0111两组、0001一组 | 4组单块足够，1组在所测预算端点下需要两块共同存在。是选定结构的条件作用，不能说已学会通用交互或证明化学协同。 |
| 生成器是否已学会提高可合成性？ | 旧task_only比较主要学习任务奖励；直接路线标量的两种子Graph为10→14、15→14，外部AiZ为9→12、13→11 | 学习证据有单次正向，也有不稳定和不改善。现阶段不能把B/Q收益归到生成器学习；R2仅有方案和算术检查，尚无分子效果结果。 |

### 关键指标纠正

常被引用的 **202→883** 是GraphGA1024中B的“外部预测器达标且路线可解”联合端点；相应纯路线是 **221→913**。外部判据使用Chemprop均值≥0.5替代RF判据，不是RF、Chemprop、路线三重交集。

固定门槛下B/C的外部联合为883/880，但纯路线为913/935。对当前“提高可合成性”的最终目标，不能用前一个+3掩盖后一个−22。任务保留是否值得，应作为显式取舍讨论，不能替代路线效果。

## 4．为什么某些时候B有效，换条件后却不占优

旧512的B对A106个确定赢例中，94个是A已评分池没有RF合格候选，12个是A有合格候选但未接受路线。94/106约88.7%，只是**赢例发生环节的比例**，不是B总贡献的因果份额。反向21个输例也保留：B有11个无RF合格候选、4个没有QED通过评分候选、6个有资格但路线预算内未解。

这与B读取的信息一致：B用任务模型贡献指导有限前体尝试，擅长解决“有限结构机会如何兼顾任务”的问题，并不是直接按合成难度打分。其机制有实际价值，但价值会受目标影响。

无RF/QED的358个原未解来源，A/B/C/A_post路线为328/319/311/328。GraphGA1015共同资格完整流程中，B_Q对A_Q是0个确定赢、2个确定输、6对未知，未知赋值下净差范围−7至0。它们提示：纯路线产出或共同构造已经近上限时，更复杂的任务定向检索未必值得。**这是适用域证据，不是否定B在所有目标下的价值，更不是要求降低最终研究目标。**

B与来源贡献检索的直接消融又说明，正确使用缺失前体信息确实能带来超出一般任务归因的结构政策收益。这项正向与上述负向应共同保留：前者回答一个具体设计是否有用，后者回答它是否已胜过强简单替代方案。

## 5．本次已经整理出的可解释性材料

五批数据已投影为[来源政策结果索引](来源政策结果索引.csv)，合计12,528条记录：旧512的3,072条、资格1024的5,120条、完整1015的4,060条、Q128的256条、选定编辑四格20条。**它们是来源位置×政策记录，不是12,528个独立样本。** 队列重叠、来源重复和同运行依赖均保留；没有把重新读取旧数据算成新增证据。

直接阅读入口：

- [政策结果概览](政策结果概览.csv)：各批次分母、已知成功与技术未知。
- [来源配对增量](来源配对增量.csv)：赢、输、平、未知和逐对可行净差范围；范围不是置信区间。
- [旧512胜负发生环节](旧512胜负发生环节.csv)：资格、候选供给、预算内路线的描述性分解。
- [差异及未知案例索引](差异及未知案例索引.csv)：保留全部差异供追查，不只挑漂亮案例。
- [已有干预案例卡](已有干预案例卡_20261029.md)：Q四个赢例、旧B/A双向案例、五组真实结构四格。
- [算法流程与可识别贡献](算法流程与可识别贡献.md)、[行级资产盘点](干预证据与行级资产盘点.md)：代码入口、字段和本地/远端保存情况。

常见误读应避免：正常耗尽约定预算，只能记“本次预算未解”；技术未知保留上下界，不填失败；保存字符串去重不等于规范分子图或骨架多样性；形成配方不能默认当作实际规划器路线；日志漏斗不等于因果中介。

现有试验不是统一完整因子设计，步骤有依赖，不能把Original到完整方法的总提升画成可相加的组件贡献饼图。这里首先依靠真实干预对照和决策日志；原子热图可辅助解释B读取什么，不能替代这些结果。关于解释忠实性与视觉解释需验证的一般方法原则，可参考[Jacovi与Goldberg，2020](https://aclanthology.org/2020.acl-main.386/)及[Adebayo等，2018](https://proceedings.neurips.cc/paper/2018/hash/294a8ed24b1ad22ec2e7efea049b8737-Abstract.html)；它们不是本项目的分子机制证据。

## 6．这些解释如何用于后续研发

**先从已经证实的价值和已经定位的不足，选择值得发展的改动。相似方法用来帮助设计和比较，而不是提前宣判方向无效。**

| 保留的候选 | 现在已有的价值 | 若继续，具体应发展什么 | 真正需要回答的问题 |
|---|---|---|---|
| B及反应约束结构构造 | 任务约束下利用前体信息改变有效构造机会，已有直接消融正向 | 把任务保留作为可选择的取舍；检查有限构造机会为何集中于重复产品、哪些结构信息有助于路线而非仅任务 | 相同资源下，相对普通结构替代能否增加不同来源、不同结构的可审计路线产出？ |
| 候选选择/联合结构提案R1 | 已有真实可执行编辑及条件响应，T2说明备选结构有价值 | 借鉴组合优化与交互建模，形成一个完整选择政策；使结构信息改变实际被执行的动作，避免大量改变被首候选成功覆盖 | 信息导向的选择是否比合理普通备选更有效，收益来自哪里、是否值得成本？已有组合优化先例不自动否定该适配。 |
| Q查询调度 | 固定结构识别及已计路线效率有实际收益 | 明确哪些状态和时间安排带来帮助，比较实际规划工作量与误漏识别，不将其包装成结构学习 | 在相关使用场景中能否减少同等路线产出的计算，或同预算找出更多真实保存路线？ |
| 生成分布改善R2 | 旧训练与路线资产可复用，当前具体方法尚未测 | 借用主动反馈/残差校正原理，解决真实采样序列、分子图重复、随机搜索标签与有限反馈适配 | 同等真实反馈成本下，未经修复的新生成输出能否更可解？适配收益及稳健性是否超过普通真反馈训练？已有数学原理不取消该问题价值。 |

以上是有依据的发展方向，不是四条自动并行计算队列。R1/R2的原理先例仍应引用，但不再要求它们具有“成熟方法原则上无法做到”的能力才值得验证。也不因某项方法已有先例，就不断转去更陌生的机制。

本轮分析的结束点是：每一步的实际改动、配对收益、损失、主要发生环节和未识别部分均能追溯；足以讨论哪项新增价值最符合目标。已经完成这轮贡献整理，不为填满图表追加新训练、路线或机制试验。进一步投入应围绕选定的完整问题，完成一次能支持取舍的验证，而非恢复无止境的微小尝试。
