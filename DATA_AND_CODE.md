# Data and code included in this deposit

The historical method is a source snapshot of the local v0.2.0 package, including its existing safety checks and tests. It is not renamed as an implementation of the later six FICEL algorithms. Its sources include adapters and author-created kernels, not downloaded upstream model distributions. Follow the package's own dependency and external-asset instructions for native execution.

`reproduction/independent1024/data` is the retained analysis projection: 1,024 original positions, 5,120 five-arm rows, predictions, saved descriptors, candidate stages and audit reports. Retained reference results remain distinct from recomputed output. Raw generation corpora, complete supplier inventory, reaction-template assets, model weights and native graph pickles are not included. Their absence does not stop saved-record arithmetic, but it means this deposit alone is not a fresh reproduction of every molecular/model measurement.

Source provenance paths remain descriptive strings. The portable entry point does not open those old paths. Files called private in older notes were prepared before the owner's 19 November 2026 public-deposit instruction. The deposit does not certify independent rights to any omitted third-party resource and adds no unrequested software license.

Machine-specific generated execution receipts and local build/render images are excluded. The public source documents, retained science records and examples are kept; later research is documented separately from these historical results.
