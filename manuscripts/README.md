# Manuscript archive

Start with the [2 October text](2026-10-02/main.pdf), then the [6 October unified main text](2026-10-06/main.pdf) and [Supplement](2026-10-06/supplement.pdf). Figures and editable Markdown/Word sources are retained beside each version.

These are dated working manuscripts. The 2 October manuscript file was retained with later corrections; its date label is not a claim that every line was frozen on 2 October. The 6 October version uses a changed qualification objective and therefore is not simply a stronger test of every earlier mechanistic claim. Subsequent research should be read through the project timeline, rather than retroactively applied to the old manuscripts.
