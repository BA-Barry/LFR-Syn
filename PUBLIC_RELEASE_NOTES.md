Server-login files, private keys, tunnel configuration, unrelated account information, raw session exports and local build output were not selected for upload. External weights, full inventories/templates, corpora and native graph pickles were also not selected. Existing scientific safeguards in the source package were preserved.

Original Word/PDF scientific drafts are retained. Original local paths in their links and data provenance are historical metadata; the saved-analysis entry point does not open them. The public evolution tree uses relative links for included files and explicitly labels references whose material is not included. Generated validation output stays ignored rather than becoming another dataset.

This release is an archive and continuation of research, not a journal submission or confirmation of the six-algorithm scheme. Original working drafts retain their dated claims and open issues. A new project-wide reuse license remains undecided.
