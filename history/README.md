# Research evolution tree

Open `research-evolution-tree.html` in a browser after downloading/cloning. The page embeds its own data and needs no network. `research_tree_data.json` is the editable record source.

After editing the JSON, run `python history/build_tree.py` from the repository root to rebuild the HTML. This small public builder uses the supplied current template; it is not the earlier local builder whose inputs predated later nodes.

This public edition retains the previous 175 historical records through 18 October 2026 and adds four explicit design/review nodes through V5.2.5 on 7 November. It updates “current” navigation without rewriting historical findings. Dates are evidence/revision dates, not new experiments or a count of independent studies.

Evidence files included in this repository have relative links. Other references show a portable historical index and “not distributed”; they cannot open a user's local disk or imply that unreleased evidence is available. The earlier SVG/screenshots and stale build script are deliberately not presented as the current graph.
